# SHILIAIWEI Brand Logo Rules (Mandatory Specification)

## 1. Zero Additions Rule (MANDATORY)
- **NEVER add anything before, after, or around the logo**:
  - No prefix words (e.g. `Official`, `Web3`, `Telegram`, `App`, `Platform`).
  - No suffix words (e.g. `Vault`, `Gaming`, `Casino`, `Mining`, `VIP`).
  - No accompanying taglines, subtitle text, or auxiliary descriptive labels directly beside the logo.
  - No icons, badges, shields, or marks prepended or appended directly into the logo container.
- **Pure Identity**: The logo consists strictly and solely of the brand wordmark unit: **`SHILIAI`** + **`[WEI]`**.

## 2. Single-Line & Tight Zero-Excess Spacing Rule
- **Always on One Line**: The logo must never wrap or split across two lines.
- **Tight Badge Alignment**:
  - The `[WEI]` rounded rectangle badge sits immediately adjacent to `SHILIAI` on the exact same line.
  - Spacing between `SHILIAI` and `[WEI]` is strictly limited to 2px–3px (LinkedIn-style `[in]` badge layout).
  - Never allow loose gaps, whitespace characters, or wide coordinate voids between `SHILIAI` and `[WEI]`.

## 3. Mutual Exclusivity Rule
- **Zero Duplicate Text**:
  - When the SHILIAIWEI logo is displayed, never display the plain text name `SHILIAIWEI` or `WEI` alongside it in the same header, card, or banner.
  - When plain text brand name is rendered in a paragraph, title, or label, never display the logo alongside it.
- **Never Standalone `WEI`**: Never use the `[WEI]` badge or the word `WEI` alone as a brand symbol without `SHILIAI`.

## 4. Mobile App Splash Screen / SplashScreen API Dimensions
- **Branded Image**: Strictly **200×80 dp** placed at the bottom third of the splash window.
- **App Icon with Background**: **240×240 dp** outer container with a **160 dp diameter circular mask** (one-third foreground masked).
- **Window Background**: Single opaque color (`#ffffff`).
- **Launch Animation Duration**: Strictly **<= 1,000 milliseconds**.
